# EventPass

EventPass is a smart event registration and check-in system that helps organizers manage event capacity, generate unique tickets, and prevent duplicate check-ins.

## Features

- Create events with capacity limits
- Register attendees
- Generate unique Ticket IDs
- Volunteer ticket check-in
- Prevent duplicate check-ins
- Live registration and check-in statistics
